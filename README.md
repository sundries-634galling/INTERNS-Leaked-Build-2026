## 🕹️ About

INTERNS is a casual life-simulation and visual-novel game set among medical interns. Build relationships, make enemies, navigate dangerous workplace intrigues, and try not to lose yourself inside the hospital system. This is an unofficial leaked pre-release build: raw, unfinished, and surfaced ahead of schedule.

For players who enjoy character-driven visual novels, casual simulations, medical settings, and messy workplace drama.

> ⚠️ **This is an unofficial leaked pre-release build.** The game is under active development: expect bugs, unfinished content, and balance changes.Archive is password protected (`2026`) to compatibility automated DMCA bots and hosting service scanners that would otherwise delete the files within hours.
